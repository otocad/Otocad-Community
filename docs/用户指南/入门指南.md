# OtoCAD 入门指南

5 分钟上手 OtoCAD 社区版 — 画出一张符合 GB/T 13323-2009 的光学零件图.

## 1. 启动与界面

启动后默认打开一张演示图纸 (双凸透镜 + 自动标注 + 双表图框), 让你立刻看到产出物长什么样.

界面布局:
- **顶部 Ribbon**: 主页 / 视图 / 标注 / 标记 / 光学 / 帮助
- **中部画布**: SkiaSharp 渲染, 鼠标中键平移, 滚轮缩放
- **右侧属性面板**: 显示当前选中实体的可编辑属性 (位置/尺寸/材料/公差等)
- **底部状态栏**: 鼠标坐标 / 缩放比例 / 实体数 / 选中数 / FPS

## 2. 基本绘图

| 操作 | 快捷方式 |
|------|---------|
| 画直线 | 主页 → 直线, 然后点两点 |
| 画圆 | 主页 → 圆, 点圆心 + 点半径 |
| 选择实体 | 直接点击; Shift + 点 加选; Ctrl+A 全选 |
| 框选 | 左→右 窗选 (完全包含才选); 右→左 框选 (相交即选) |
| 移动选中 | 直接拖动 |
| 撤销/重做 | Ctrl+Z / Ctrl+Y |
| 缩放 | 滚轮; Ctrl+= / Ctrl+- / Ctrl+0 (回到原始视图) |

## 3. 画一个光学元件

### 单透镜
1. 切到 **光学** Ribbon → 点 **单透镜**
2. 在 wizard 里填: 通光直径 / 中心厚度 / R1 / R2 / 玻璃牌号 (内置 40+ 牌号自动填 n_d, v_d)
3. 点 **确定 (放置)**, 在画布上点击放置位置
4. 透镜出来后自带光轴线 (双点画线, 符合 GB/T 13323-2009 §2.1)

### 双胶合透镜 / 通用透镜
同样的入口 — **光学** Ribbon → 双胶合 / 通用透镜, wizard 流程一致.

## 4. 自动标注

选中透镜后 → 点 **光学 → 自动标注** → 自动生成 R1 / R2 / d (中心厚) / φ (通光直径) 4-5 个尺寸标注.

- 改透镜参数 (R1 = 50 → 80) → 标注自动跟随
- 文字格式遵循 GB/T 13323-2009 §1.1 (公称值 / 实际值±公差 / 参考值括号)
- 平面表面自动显示 "R∞"

## 5. 手动标注

- **半径**: 标注 Ribbon → 半径标注, 然后**单击**圆/弧/透镜表面
- **直径**: 类似, 单击即出
- **线性 / 对齐**: 单击 Line 实体一键标注, 或依次点两端点

拖动标注上的中点 grip 可调整位置 (半径不变).

## 6. 光学标记 (符号)

**标记** Ribbon 提供 24 种 ISO 10110 / GB 标记:
- 镀膜符号 (AR / HR / 部分反射 / 偏振等 13 类)
- 表面缺陷 (4/N(ΔN) 面形 / 5/B 表面疵病 / C 中心偏差 ...)
- 加工标记 (黑化 / 抛光 / 喷砂 / 金刚石车削 / 研磨)
- 工艺备注 (装配 / 检验 / 加工 / 材料缺陷)

点 mark 按钮 → 在画布上点击放置.

## 7. 保存与导出

| 操作 | 方式 |
|------|------|
| 保存 | Ctrl+S (原生 `.otocad` 格式, JSON) |
| 另存为 | Ctrl+Shift+S |
| 新建 | Ctrl+N |
| 打开 | Ctrl+O |
| 导出 DXF | 文件 → 导出 DXF (AutoCAD 2000+ 兼容) |
| 导出 PDF | 文件 → 导出 PDF (A4 横向矢量) |
| 打印 | Ctrl+P (Skia 系统打印, 跨平台) |

AutoSave 每 30 秒自动备份 (在 `%APPDATA%/OtoCAD/autosave/`).

## 8. 常见问题

**Q: 自动标注的位置不好看怎么办?**
A: 拖动标注上的 grip 重新摆放. 中点 grip 改 dim 线位置, 端点 grip 改测量参考点.

**Q: 改了透镜参数, 标注没更新?**
A: 自动标注是关联式的 — 只要透镜还在画布上, 改 R1/直径等会自动重算标注. 如果没刷新, 重新点 **自动标注** 按钮.

**Q: AI 助手不能用?**
A: 社区版只有 ChatPanel 脚手架 UI, 实际 AI 服务在 **OtoCAD Cloud** (商业版). 见 README "Community vs Cloud" 表.

**Q: 光轴怎么关?**
A: 选中透镜 → 属性面板 → 取消勾选 "ShowOpticalAxis".

**Q: 怎么改标注风格 (字高 / 箭头 / 精度)?**
A: 主页 → 设置 → 标注标准, 切换 ISO / GB / GB-Optical 预设.
